Data pipeline · AI · private code

AI document extraction, schema mapping and bank reconciliation

Financial documents and ledger exports all lay out and name their data differently, so reconciling them usually starts with typing and manual cleaning. I built one pipeline that takes a raw document to a finished reconciliation and explains its own decisions.

  • OCR and language models read the documents and extract the tables, so people check results instead of typing them.
  • Works out what each column is from its name and values, scores its confidence, sends uncertain cases to a person, and keeps an audit trail.
  • Repairs the cells, then reconciles a bank statement against a cash book.
  • A discovery engine finds the keys, formulas and root-cause cells across related tables from the values alone, explains each finding with evidence, and stores every run in PostgreSQL.
  • Tested against synthetic statements with a known correct answer, to find where it breaks.

Python · Polars · Pydantic · Pandera · PostgreSQL · about 22,800 lines · 298 tests. The code is private because it handles sensitive data.
