Schema mapping and bank reconciliation pipeline

Every bank statement and ledger export names and formats its columns differently, so reconciling them usually starts with manual mapping and cleaning. I built a pipeline that does that work and explains its own decisions.

  • Profiles a raw file and works out what each column is from its name and its values.
  • Scores its confidence, sends uncertain mappings to a person, and keeps an audit trail of every decision.
  • Repairs the cells, then reconciles the statement against a cash book.
  • Traces a broken balance back to the cell or decision that caused it, shows what would change if a rule changed, and learns new matching rules from labelled data.

Python · Polars · Pydantic · Pandera · about 19,000 lines · 219 unit tests. The code is private because it handles sensitive data.
