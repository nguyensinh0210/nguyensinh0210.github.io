Privacy Policy — Channel Manager

Last updated: 7 November 2026

What the app is

Channel Manager is a personal desktop application that runs only on its owner's computer. It publishes videos and posts to the owner's own YouTube channel, TikTok account and Facebook Page.

Data accessed

  • YouTube (Google): permission to upload videos (youtube.upload) and to read basic channel information such as the channel name and statistics (youtube.readonly).
  • TikTok: basic profile information and permission to upload or publish videos.
  • Facebook: the list of Pages you manage and permission to publish posts and videos to them.

How data is stored and used

  • Access tokens are stored only on the owner's computer, encrypted, with the key protected by the Windows account.
  • Data is used only to publish content that the owner chooses and to show the connection status.
  • No data is sold, shared with third parties, sent to any server operated by the developer, or used for advertising.

Google API Services

Channel Manager's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. It also uses YouTube API Services; see the Google Privacy Policy.

Revoking access and deleting data

You can revoke access at any time from your Google, TikTok or Facebook account settings, or with the app's logout command, which also deletes the locally stored tokens.
